# Abandoned match result decision

When SIXFL admin marks a referee-abandoned fixture, admin can now either leave the league result pending or award a 3-0 result to either team.

An awarded result is stored separately from the score at the moment of abandonment, becomes the official MatchResult used by the league table, and is included in both abandonment emails. The fee decision remains independent: if one team caused the abandonment, that team still pays both match fees and the innocent team is not charged.
