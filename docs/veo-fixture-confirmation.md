# Veo at fixture confirmation

Veo-enabled leagues offer No thanks, Just this match, or This and future matches on the captain fixture-confirmation page. Both affirmative choices have equal allocation priority; the latter saves a default for future confirmations in the same league. No thanks skips the selected match without changing that default. Turn off future Priority withdraws pending recurring requests but keeps explicit one-offs and accepted bookings.

The shared captain form also appears for late positive confirmations and already-confirmed fixtures. The dashboard and nudge route link to this form. Administrator/captain previews show the same disabled choices, no live consent form. Server actions and the database service check the real active captain of the exact participating team. Confirmation is its own transaction: an optional request error never undoes attendance. No opt-in is inferred from a missing input.

Admin: League current season → Veo Priority → Fixture requests and filming decisions. Choose the date, review and confirm the whole physical camera evening. Leagues sharing the same venue/pitch use one combined capacity, not separate allowances. Only same-time, same-duration pitch swaps are permitted. Confirmation and current membership are rechecked, stale decisions refused, old publication snapshots and accepted bookings locked. No opponent/time/base-price changes. A named venue is required.

A request or slot acceptance takes no money. After the completed game, the administrator supplies a usable YouTube/SIXFL recording URL and confirms it ready. Each accepted positive-fee team gets one separate £5 Team payments charge, deliberately without fixtureId so it cannot replace the existing per-fixture match charge. Free fixtures stay free. The existing checkout/payment ledger processes this ordinary optional charge; no SMS, email, saved-card debit or real provider request is initiated by this feature. There is no late admin fee on the optional £5.

Failed/cancelled recordings are not billed. Closing a billed booking voids only its linked Veo charges and returns actual receipts (including credit payments) to the existing team credit ledger with a stable key. Scoped database guards preserve that state if a late checkout receipt arrives, and reconcile a later receipt correction. They never create credit for unpaid money. Normal fixture cancellation/postponement closes the optional booking too. Changing an accepted booking's teams/time/venue/pitch requires cancelling it first. Closed bookings cannot be billed again.

The additive migration enables confirmation-time mode without enabling any league or team, changing base fees, or rewriting historical Veo snapshots. Legacy publication tests explicitly retain the old mode to protect earlier agreements. Rollout includes no actual captain opt-in, finalisation, payment or customer communication.
